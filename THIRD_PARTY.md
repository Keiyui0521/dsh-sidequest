# Third-party components

Dependencies are installed from npm; no DeepSeek Harness or Codex source code is included.

- [Marked](https://github.com/markedjs/marked): MIT.
- [DOMPurify](https://github.com/cure53/DOMPurify): Apache-2.0 OR MPL-2.0.
- [KaTeX](https://github.com/KaTeX/KaTeX): MIT; its fonts carry the licenses distributed with KaTeX.
- [esbuild](https://github.com/evanw/esbuild): MIT, build-time only.

`npm run build` retains legal comments in the generated browser bundle. The original dependency license files remain in their installed packages. These components retain their respective licenses; the project MIT license applies to SideQuest's own code.
